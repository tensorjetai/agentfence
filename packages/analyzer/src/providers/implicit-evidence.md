Evidence is pinned to immutable upstream commits matching the provider refs modeled by this analyzer.

GitHub's [webhook payload documentation](https://docs.github.com/en/webhooks/webhook-events-and-payloads#pull_request_review_comment) identifies `comment` as the comment object for `pull_request_review_comment`; thus its body path is `github.event.comment.body`, not `github.event.review_comment.body`. The `pull_request` object provides the associated PR context. For `issue_comment`, the payload likewise contains `comment` and `issue`; for `pull_request_review`, it contains `pull_request` and `review`.
